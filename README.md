# TIA Project Converter

Experimental, local-first tooling for migrating Siemens TIA Portal projects between major versions, with **V17 as the minimum target for the first supported release**.

This repository starts with an honest migration planner and project metadata inspector. Full project conversion will require installed, licensed TIA Portal versions and their matching TIA Openness APIs; the browser site will not pretend to rewrite proprietary project databases by itself.

See [docs/product-spec.md](docs/product-spec.md) for the acceptance contract.
